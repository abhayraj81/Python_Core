## About

This repository tracks my day-to-day Python practice — one folder per topic, one file per concept or assignment, in the order I learned them. Each script is self-contained and runnable on its own, with inline comments explaining what's being demonstrated.

## Topics Covered

- Variables, data types, and type casting
- Console I/O with `print()` and `input()`
- Arithmetic, comparison, and logical operators
- Conditional logic: `if` / `elif` / `else`, nested and ternary forms
- Functions: parameters, arguments, default values, return values
- String operations: indexing, slicing, formatting, built-in methods

## Running the Scripts

Each file runs independently:

```bash
python "01-python-basics/01-hello-world-print-basics.py"
```

Requires Python 3.x — no external dependencies.
